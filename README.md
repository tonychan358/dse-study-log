# DSE 溫習日誌

給中六學生記錄每日溫習時數、心情與反思的網頁應用程式，可加至手機主畫面當作 App 使用。老師可檢視全班進度並撰寫評語。

**網址**：https://tonychan358.github.io/dse-study-log/

## 功能

- **每日記錄**：以日曆介面輸入各科溫習時數（0.25–12 小時，每 0.25 遞增）、心情與當日反思
- **一鍵分享**：記錄完成後可複製當日摘要，方便經 WhatsApp 向老師報告進度
- **週報**：本週各科時數、與上週比較、連續記錄天數
- **老師檢視**：全班總覽、個別學生報告、撰寫評語
- **中英切換**與**亮／暗色主題**
- **離線可用**：無網絡時仍可輸入，回復連線後自動補傳
- **可安裝**：加至主畫面後以獨立視窗開啟，操作體驗接近原生 App

## 技術

前端為原生 ES modules，**無建置步驟、無 npm、無 CDN 依賴**——修改檔案後直接重新載入瀏覽器即可見效。後端使用 Google Apps Script Web App，資料存放於 Google 試算表。

## 自行架設

資料層與後端的完整設定步驟（建立試算表、貼上 `Code.gs`、部署 Web App）請見 [`gas/README.md`](gas/README.md)。建立試算表時可開啟 [`gas/setup-helper.html`](gas/setup-helper.html)，逐格複製表頭與種子資料。

設定完成後，把部署所得的 Web App 網址填入 `js/api.js` 的 `GAS_URL` 常數。

## 本機開發

```bash
python -m http.server 8005
```

或直接執行 `啟動溫習日誌.bat`（會自動開啟瀏覽器），關閉時執行 `關閉溫習日誌.bat`。

測試：瀏覽器開啟 `tests.html` 執行前端測試；後端測試執行 `node gas/test-local.mjs`。

## 安全性說明

本系統的帳戶密碼以**明文**儲存於 Google 試算表（為方便老師管理而作的取捨）。因此：

- 該試算表**不得**與任何人共用，「一般存取權」須設為「限制」
- 請勿使用你在其他網站也在使用的密碼
- 學生密碼建議使用隨機字串，避免使用學號或生日

前端只會在瀏覽器儲存 session token，**不會**儲存密碼。
